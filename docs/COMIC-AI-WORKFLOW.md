# Comic Workflow V2 (Simple Cloud-Only)

Цель: делать комикс быстро и стабильно, без локальных тяжелых инструментов.

## Главное решение

`ComfyUI` вам не нужен для production.

Используем только облачный стек:
- Сценарий и режиссура: `GPT-5.2`
- Кадры комикса: `gpt-image-1.5`
- Анимация кадров: `sora-2`

## Почему без ComfyUI

- На вашем ПК он работает нестабильно.
- Cloud-цепочка с ComfyUI слишком сложная.
- Сложность выше, чем прирост качества.
- Для ваших целей (веб-комикс + анимация) API-пайплайн проще, быстрее и предсказуемее.

## Новый процесс (без лишнего)

1. Пишем сцену в `GPT-5.2`:
- описание страницы
- список панелей
- эмоции и действия персонажей

2. На каждую панель делаем 2 финальные версии в `gpt-image-1.5`:
- `portrait` (mobile)
- `landscape` (desktop)

3. Из финального кадра делаем анимацию в `sora-2`:
- 2-4 секунды
- легкое движение (камера/волосы/дым/свет)

4. Публикация:
- основной формат `mp4/webm`
- `gif` только как fallback

## Качество

- Черновики: `medium`
- Финал статики: `high`
- Анимация: `sora-2` как дефолт

## Как держать единый стиль годами

1. Один `Style Bible` (палитра, линия, тени, запреты).
2. Один `Character Bible` (лица, руки, рост, возрастные этапы).
3. Один мастер-промпт на сериал.
4. Всегда референсить предыдущий утвержденный кадр персонажа.

## Минимальный бюджетный расчет

Пусть:
- `N = pages * panels_per_page`
- `D = seconds_per_panel`

Тогда:
- Статика: `N * (portrait_price + landscape_price)`
- Анимация: `N * D * video_price_per_sec`
- Текст: `input_cost + output_cost`

Итог: `Text + Static + Animation`

Для production-комикса используем только этот cloud-only workflow.
